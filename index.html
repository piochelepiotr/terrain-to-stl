Water

When checked, lake/river polygons are pulled from OpenStreetMap and every point inside a lake is set to one flat elevation, instead of following noisy raw terrain data.

Exaggerates flattened lakes 100m above their real elevation so their outline is unmistakable in the preview — use this to visually check the detected shape against the real lake before turning it off.

Model

3MF export needs room beside the model for both the AMS exclusion zone at the front-left of the plate and the multi-color prime/wipe tower (Bambu Studio always requires one when a print uses more than one filament, so it can't just be turned off). Tiles up to ~176mm leave enough margin for both on a 256x256mm bed (P1S/P2S/X1/X1C); above that, Bambu Studio may warn about exclusion-zone or prime-tower collisions since there's no clear space left to place them.

With a multi-tile grid, this is the base thickness of the tile containing the lowest point in the whole grid. Every other tile gets a thicker base so all tiles' bottoms sit on the same physical plane when assembled — a tile that's entirely up a mountain gets a proportionally thicker base.

Views the model from nearly overhead instead of the default angle — useful for checking whether flat areas (lakes, plateaus) actually look flat, since the default angled view can hide small flat patches next to tall peaks.

Color by elevation

Preview-only: colors each point of the 3D preview by which elevation band it falls in. STL files have no standard way to store color, so exported files are still plain (uncolored) geometry regardless of this setting.
